# CC Brand Board

Статический веб-интерфейс для бренд-борда SKU сигарет (BAT | JTI | KT&G | PMI | OTHERS). Сервер не нужен — работает на GitHub Pages, данные лежат в репозитории.

## Запуск
Settings → Pages → Source: *Deploy from a branch* → ветка `main`, папка `/ (root)`.
Вход: `Test1` / `TestViev@)_001`.

## Файлы
- `data/board.json` — период и список SKU (название, сегмент, цена, компания, SoM, изменение, фото)
- `images/` — фото пачек
- `index.html`, `style.css`, `app.js` — интерфейс

## Возможности
- Борд: строки — ценовые уровни внутри сегментов PREMIUM / MEDIUM / LOW, колонки — компании, SoM по компании в шапке
- Добавление / редактирование / удаление SKU, загрузка фото пачки
- Перетаскивание карточки в другую ячейку меняет компанию, цену и сегмент
- Импорт Excel (колонки Family/SKU, Segment, Price, Company, SoM, Point Change) и экспорт в Excel
- Печать / PDF (A3 альбом)
- «Сохранить в GitHub» — коммит `data/board.json` и фото через GitHub API (нужен fine-grained токен с правом Contents: write). До сохранения правки хранятся черновиком в браузере.

> Пароль проверяется в браузере — это защита интерфейса, а не данных. Для закрытости держите репозиторий приватным.
